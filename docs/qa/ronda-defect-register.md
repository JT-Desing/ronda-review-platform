# Registro de defectos y correcciones

Entorno exclusivamente QA. “Corregido” describe el caso específico, no el cierre del objetivo ni de toda la sección. Evidencia detallada en ronda-browser-cases.csv y documentos second-pass-*.

UX-055 (M249): la navegación lateral «Proyectos» no salía del detalle de equipo porque `currentView` ya era `projects` y el handler retornaba antes de inspeccionar la subruta. Corregido para volver a la galería del mismo equipo, manteniendo el guard de borradores. Regresión, suite completa y build pasan. Retest UI 2026-10-19 pasó en QA persistente aislado: detalle → Proyectos regresó a la galería del mismo equipo; ruta, árbol accesible y screenshot coincidieron. No había borrador para comprobar el diálogo de descarte.

M197 (frame antiguo al pasar de Personal a Proyectos): en un Edge QA nuevo, dos transiciones adicionales desde Personal devolvieron la galería del equipo en la primera captura; `#projects`, árbol accesible, espacio y proyecto coincidieron en ambos ciclos. La observación previa de un frame personal no se reprodujo. Se mantiene PARTIAL (intermitencia no excluida) porque la herramienta de captura no registra cuadros de compositor/video; no se cambió código sin evidencia reproducible.
